# 강산재 한옥호텔 공식 홈페이지

강원특별자치도 홍천군 4만 평 숲속의 전통 한옥 독채 숙소, 강산재의 공식 홈페이지입니다.

**배포 방법은 [배포가이드.md](./배포가이드.md) 를 보십시오.**

---

## 기술 구성

| 항목 | 내용 |
|---|---|
| 형태 | 정적 사이트 (빌드 도구 없음) |
| 언어 | HTML5 · CSS3 · Vanilla JS |
| 서체 | Noto Serif KR (제목) · Pretendard (본문) |
| 배포 | Vercel |
| 페이지 | 4개 |
| 이미지 | 44장 |

빌드 과정이 없습니다. `index.html` 을 브라우저로 열면 그대로 확인됩니다.

---

## 디자인 토큰

`assets/style.css` 최상단 `:root` 에 모여 있습니다. 여기만 고치면 전 페이지에 반영됩니다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--paper` | `#f7f4ed` | 기본 배경 (한지) |
| `--ink` | `#191714` | 본문 · 푸터 |
| `--ochre` | `#9c6239` | 주요 버튼 · 강조 |
| `--pine` | `#2f3a31` | 반전 섹션 |
| `--gold` | `#c2a05a` | 최소 강조 |

**디자인 원칙** — 직각 고정(둥근 모서리 없음), 그림자 없음, 여백 우선.
펜션이 아니라 갤러리의 문법을 따릅니다.
